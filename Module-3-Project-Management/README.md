# 📊 Module 3 – Project Scope Management Plan & Work Breakdown Structure (WBS)

## 📌 Objective  
To define clear project boundaries, control scope, and structure the HealthFirst Cares project into manageable tasks for effective planning and execution.

## 📄 Project Scope Management Plan  

### Work Done:
Defined project objectives focused on:
- Reducing patient wait time  
- Improving appointment scheduling  
- Enhancing stakeholder communication  
- Optimizing resource allocation  

Identified in-scope activities:
- Implementation of Hospital Information System (HIS)  
- Centralized Electronic Health Records (EHR)  
- Real-time appointment scheduling  
- Automated notifications  
- Resource tracking and dashboards  
- Interdepartmental communication system  

Defined out-of-scope activities:
- Hiring additional staff  
- Infrastructure expansion  
- Procurement of new equipment  
- Network upgrades  

Identified constraints:
- Budget and timeline limitations  
- Dependency on existing systems  
- Data privacy and security requirements  
- Stakeholder availability and resistance to change  

## 📊 Work Breakdown Structure (WBS)

### Work Done:
Structured the project into hierarchical levels:

- Level 1: HealthFirst Cares Project  
- Level 2: Project Phases  
- Level 3: Tasks and Subtasks  

Defined:
- Task names and descriptions  
- Task owners (Business Analyst, Project Manager, Data Analyst)  
- Deliverables and milestones  
- Estimated durations  

Ensured all WBS components are aligned with the defined project scope.

## 🧠 Skills Used:
- Project planning: Structured project phases and tasks  
- Scope management: Defined boundaries to prevent scope creep  
- Analytical thinking: Ensured alignment between scope and execution  
- Organizational skills: Broke down complex work into manageable units  
- Documentation: Created structured and professional project artifacts  

## 📌 Outcome  
A well-defined project structure that:
- Clearly establishes scope boundaries  
- Breaks down the project into manageable tasks  
- Aligns planning with execution  
- Reduces risk of scope creep and miscommunication
