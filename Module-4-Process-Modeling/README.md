
# 🔄 Module 4 – Process Modeling (AS-IS & TO-BE)

## 📌 Objective  
To analyze existing hospital processes, identify inefficiencies, and design optimized workflows using AS-IS and TO-BE process models.

## 📄 AS-IS Process Analysis  

### Work Done:
Analyzed the current Patient Appointment & Consultation process  

Identified key steps:
- Manual appointment booking  
- Manual availability checking  
- Patient waiting without real-time updates  
- Delays in lab processing  
- Lack of coordination between departments  

### Key Issues Identified:
- Long patient wait times  
- High no-show and rescheduling rates  
- Scheduling conflicts and overbooking  
- Delayed lab results  
- Poor interdepartmental communication  

## 🚀 TO-BE Process Design  

### Work Done:
Designed an improved process using a Hospital Information System (HIS)  

Key improvements:
- Online appointment booking  
- Real-time doctor availability tracking  
- Automated notifications (SMS/Email)  
- Queue management system  
- Integrated lab result updates  
- Centralized patient records
